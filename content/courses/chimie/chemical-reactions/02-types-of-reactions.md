## What you will learn

- the main types of reaction and how to recognise each;
- combustion (complete and incomplete), neutralisation, decomposition, displacement, redox and precipitation;
- how to classify a given equation.

## 1. Classification

| Type | Pattern | Example |
|---|---|---|
| Combination (synthesis) | $\text{A} + \text{B} \to \text{AB}$ | $2\text{Mg} + \text{O}_2 \to 2\text{MgO}$ |
| Decomposition | $\text{AB} \to \text{A} + \text{B}$ | $2\text{H}_2\text{O}_2 \to 2\text{H}_2\text{O} + \text{O}_2$ |
| Displacement | $\text{A} + \text{BC} \to \text{AC} + \text{B}$ | $\text{Fe} + \text{CuSO}_4 \to \text{FeSO}_4 + \text{Cu}$ |
| Double displacement | $\text{AB} + \text{CD} \to \text{AD} + \text{CB}$ | precipitation, neutralisation |
| Combustion | burns in oxygen | $\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$ |

Redox cuts across these types (electron transfer).

## 2. Combustion

- **Complete** combustion (plenty of oxygen): carbon dioxide and water, e.g. $\text{C}_3\text{H}_8 + 5\text{O}_2 \to 3\text{CO}_2 + 4\text{H}_2\text{O}$; blue flame.
- **Incomplete** combustion (limited oxygen): carbon monoxide (toxic) and/or carbon (soot): $2\text{CH}_4 + 3\text{O}_2 \to 2\text{CO} + 4\text{H}_2\text{O}$; yellow smoky flame.

## 3. Neutralisation

Acid + base $\to$ salt + water; ionic equation $\text{H}^+ + \text{OH}^- \to \text{H}_2\text{O}$. Exothermic. Example: $\text{HCl} + \text{NaOH} \to \text{NaCl} + \text{H}_2\text{O}$.

## 4. Decomposition

- **Thermal**: $\text{CaCO}_3 \xrightarrow{\Delta} \text{CaO} + \text{CO}_2$; $2\text{HgO} \to 2\text{Hg} + \text{O}_2$.
- **Catalytic**: $2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2$.
- **Electrolytic**: $2\text{H}_2\text{O} \to 2\text{H}_2 + \text{O}_2$.

## 5. Displacement

A more reactive metal displaces a less reactive one from its salt: $\text{Zn} + \text{CuSO}_4 \to \text{ZnSO}_4 + \text{Cu}$; $\text{Cl}_2 + 2\text{KBr} \to 2\text{KCl} + \text{Br}_2$ (halogen displacement). It is a **redox** reaction (Zn oxidised, $\text{Cu}^{2+}$ reduced). Iron forms iron(II) in such reactions.

## 6. Redox and precipitation

**Redox** (oxidation–reduction): electrons are transferred; recognise it by oxidation-number changes ("OIL RIG"). **Precipitation**: two solutions form an insoluble solid, e.g. $\text{Pb(NO}_3)_2 + 2\text{KI} \to \text{PbI}_2\downarrow + 2\text{KNO}_3$ (a yellow precipitate).

**Example 1.** Classify $\text{Fe} + \text{CuSO}_4 \to \text{FeSO}_4 + \text{Cu}$: displacement (and redox).

**Example 2.** Classify $2\text{H}_2\text{O}_2 \to 2\text{H}_2\text{O} + \text{O}_2$: decomposition.

**Example 3.** Classify $\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$: combustion (redox).

**Example 4.** Classify $\text{NaOH} + \text{HCl} \to \text{NaCl} + \text{H}_2\text{O}$: neutralisation (double displacement, not redox).

## Common mistakes

- Calling every reaction with oxygen "combustion" (rusting is slow oxidation).
- Forgetting that displacement is redox.
- Thinking neutralisation changes oxidation numbers.

## Practice problems

1. Classify $2\text{Mg} + \text{O}_2 \to 2\text{MgO}$ and $\text{CaCO}_3 \to \text{CaO} + \text{CO}_2$.
2. Why does incomplete combustion produce a yellow flame?

**Answers.** (1) Combination (redox); thermal decomposition. (2) Unburnt carbon particles glow.
