## What you will learn

- word and symbol equations;
- how to balance an equation, with state symbols;
- ionic equations and the conventions of the Chinese curriculum.

## 1. Equations

A **word equation** names the reactants and products: magnesium + oxygen $\to$ magnesium oxide. A **symbol equation** uses formulae and must be **balanced**: the same number of each kind of atom (and the same total charge) on both sides, using whole-number **coefficients** (never by changing subscripts).

**State symbols**: $(s)$ solid, $(l)$ liquid, $(g)$ gas, $(aq)$ aqueous. Conditions go above the arrow (heat $\Delta$, catalyst, high temperature).

## 2. Balancing method

1. Write the correct formulae.
2. Balance metals first, then non-metals, then H and O last.
3. Start with the element that appears in the fewest places, or the "hard" element (such as O).
4. Check every element at the end.

**Example 1.** $\text{Fe} + \text{O}_2 \to \text{Fe}_2\text{O}_3$: O: $2$ vs $3$ — use $6$ atoms: $3\text{O}_2$ and $2\text{Fe}_2\text{O}_3$; then $4\text{Fe}$: $4\text{Fe} + 3\text{O}_2 \to 2\text{Fe}_2\text{O}_3$.

**Example 2.** $\text{CH}_4 + \text{O}_2 \to \text{CO}_2 + \text{H}_2\text{O}$: C balanced; H: $4$ so $2\text{H}_2\text{O}$; O: $4$ so $2\text{O}_2$: $\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$.

**Example 3.** $\text{Al} + \text{HCl} \to \text{AlCl}_3 + \text{H}_2$: $2\text{Al} + 6\text{HCl} \to 2\text{AlCl}_3 + 3\text{H}_2$.

**Example 4.** $\text{C}_3\text{H}_8 + \text{O}_2 \to \text{CO}_2 + \text{H}_2\text{O}$: $\text{C}_3\text{H}_8 + 5\text{O}_2 \to 3\text{CO}_2 + 4\text{H}_2\text{O}$.

## 3. Ionic equations

Write strong electrolytes (soluble salts, strong acids and bases) as ions, cancel the **spectator ions**, and keep solids, gases, water and weak electrolytes as formulae. Check that the charge is balanced.

$$
\text{AgNO}_3(aq) + \text{NaCl}(aq) \to \text{AgCl}(s) + \text{NaNO}_3(aq) \ \Rightarrow\ \text{Ag}^+(aq) + \text{Cl}^-(aq) \to \text{AgCl}(s).
$$

Neutralisation: $\text{H}^+ + \text{OH}^- \to \text{H}_2\text{O}$. Precipitation: $\text{Ba}^{2+} + \text{SO}_4^{2-} \to \text{BaSO}_4\downarrow$.

## 4. Chinese convention (化学方程式)

Write the **conditions** over the arrow ($\Delta$, "点燃" ignition, "高温" high temperature, catalyst). Use $\uparrow$ for a gas produced and $\downarrow$ for a precipitate when the reactants are not themselves gas/solid. Weak electrolytes ($\text{CH}_3\text{COOH}$, $\text{NH}_3\cdot\text{H}_2\text{O}$), oxides, precipitates and gases stay in molecular form in ionic equations.

## Common mistakes

- Changing subscripts instead of coefficients.
- Forgetting state symbols or conditions.
- Leaving spectator ions in an ionic equation.

## Practice problems

1. Balance $\text{Na} + \text{H}_2\text{O} \to \text{NaOH} + \text{H}_2$.
2. Write the ionic equation for $\text{BaCl}_2 + \text{Na}_2\text{SO}_4$.
3. Balance $\text{C}_2\text{H}_6 + \text{O}_2 \to \text{CO}_2 + \text{H}_2\text{O}$.

**Answers.** (1) $2\text{Na} + 2\text{H}_2\text{O} \to 2\text{NaOH} + \text{H}_2$. (2) $\text{Ba}^{2+} + \text{SO}_4^{2-} \to \text{BaSO}_4\downarrow$. (3) $2\text{C}_2\text{H}_6 + 7\text{O}_2 \to 4\text{CO}_2 + 6\text{H}_2\text{O}$.
