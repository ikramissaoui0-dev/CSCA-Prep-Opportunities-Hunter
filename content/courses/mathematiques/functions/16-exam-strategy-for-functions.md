## What you will learn

- the question types on functions;
- a decision checklist for each type;
- the common traps.

## 1. Question types and approach

| Type | Approach |
|---|---|
| Domain / range | list every condition (denominator, root, log), intersect; for range: complete the square, bounds, solve for $x$ |
| Evaluation | decide which piece or formula applies, substitute |
| Properties | even/odd test on a symmetric domain; monotonicity; injectivity before inverting |
| Inverse / composite | solve for $x$; apply the inner function first |
| Transformations | horizontal operations act on $x$ (opposite way), vertical on $y$; track one key point |
| Exponential / log equations | one common base, $t = a^x$ substitution, check the domain |
| Sequences | recognise the type; use $a_n = S_n - S_{n-1}$ for given $S_n$ |
| Power functions | match the exponent to the shape; parameter problems from the coefficient $= 1$ |
| Trigonometric functions | period $\dfrac{2\pi}\omega$, range, monotonic interval, five points |

## 2. Top tips

1. **Domain first.** Write every condition before doing anything else.
2. On multiple choice, **test one value** (for example $x = 0$ or $x = 1$) to eliminate options for parity, domain or graph.
3. For graph-reading questions, identify transformations in order and follow one point.
4. For log equations, **check solutions against the domain**.
5. For trigonometric equations, give **all** solutions in the stated interval.
6. For $S_n$ questions, treat $n = 1$ separately.
7. Reduce the angle to a first-quadrant reference angle with the unit circle.

## 3. Traps

- Reading $f^{-1}$ as $\dfrac1f$.
- Shifting a graph in the wrong direction.
- Dividing by $\sin x$ and losing roots.
- Using the geometric sum formula with $q = 1$.
- Ignoring the base being below $1$ in a log or exponential inequality.

## Quick self-test

1. Domain of $f(x) = \dfrac{\ln(x - 1)}{\sqrt{4 - x}}$.
2. For a geometric sequence $a_1 = 2$ and $S_3 = 14$. Find $q$.
3. Solve $2\sin x - 1 = 0$ on $[0, 2\pi]$.

**Answers.** (1) $(1, 4)$. (2) $q^2 + q - 6 = 0$: $q = 2$ or $-3$. (3) $\dfrac\pi6$, $\dfrac{5\pi}6$.
