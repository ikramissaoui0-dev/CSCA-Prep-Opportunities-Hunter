## One-page summary

**Limits.** $\lim\dfrac{\sin x}x = 1$, $\lim\dfrac{e^x - 1}x = 1$, $\lim\dfrac{\ln(1 + x)}x = 1$, $\lim\left(1 + \dfrac1n\right)^n = e$.

**Derivatives.** $(x^n)' = nx^{n-1}$, $(e^x)' = e^x$, $(a^x)' = a^x\ln a$, $(\ln x)' = \dfrac1x$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$, $(\tan x)' = \dfrac1{\cos^2x}$. $(uv)' = u'v + uv'$, $\left(\dfrac uv\right)' = \dfrac{u'v - uv'}{v^2}$, $(f(g))' = f'(g)g'$. Tangent: $y - f(a) = f'(a)(x - a)$.

**Applications.** $f' > 0$: increasing; $f' < 0$: decreasing; extremum where $f'$ changes sign; $f'' > 0$ at a critical point: minimum.

**Integrals.** $\int x^n = \dfrac{x^{n+1}}{n+1}$, $\int\dfrac1x = \ln|x|$, $\int e^x = e^x$, $\int\sin x = -\cos x$, $\int\cos x = \sin x$; $\int_a^bf = F(b) - F(a)$; area $\int(f - g)$; volume of revolution $\pi\int f^2$.

**Counting and probability.** $P(n, k) = \dfrac{n!}{(n - k)!}$, $C(n, k) = \dfrac{n!}{k!(n - k)!}$, $(a + b)^n = \sum\binom nka^{n-k}b^k$. $P(A \cup B) = P(A) + P(B) - P(A \cap B)$, $P(B \mid A) = \dfrac{P(A \cap B)}{P(A)}$. Binomial: $E = np$, $D = np(1 - p)$.

**Statistics.** $\bar x = \dfrac1n\sum x_i$; $s^2 = \overline{x^2} - \bar x^2$; $y = ax + b$: $\bar y = a\bar x + b$, $s_y^2 = a^2s_x^2$. Normal: $68.3\%$, $95.4\%$, $99.7\%$ within $1, 2, 3\sigma$; regression line passes through $(\bar x, \bar y)$.

## Common slips

- Mixing derivative and integral of $\sin$/$\cos$.
- Missing the chain-rule factor.
- Forgetting the complement in "at least one".

## Quick check

1. $(x\ln x)'$.
2. $\int_0^1e^{2x}dx$.
3. $\binom62$.

**Answers.** (1) $\ln x + 1$. (2) $\dfrac{e^2 - 1}2$. (3) $15$.
