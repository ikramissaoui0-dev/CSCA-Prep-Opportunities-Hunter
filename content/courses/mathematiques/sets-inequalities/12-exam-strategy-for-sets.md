## What you will learn

- the question types on sets and inequalities and how much time to give each;
- a short checklist that avoids the usual lost marks.

## 1. Question types

| Type | Typical task | Method |
|---|---|---|
| Direct computation | $A \cup B$, $A \cap B$, $A'$ | list or use a number line |
| Counting | $\lvert A \cup B\rvert$, Venn diagrams | inclusion–exclusion, fill from the centre |
| Word problems | surveys, divisibility | translate to set language, draw |
| Inequalities | solve and give an interval | sign analysis |
| Combined | $B \subseteq A$ with a parameter, "for all $x$" | cases, discriminant, check $\varnothing$ |

## 2. Time allocation

In a paper of 48 questions, Sets & Inequalities typically gets about 8 questions. Aim for roughly $75$ seconds per question: if one question needs more than two minutes, mark it and come back.

## 3. Top strategies

1. **Read the question twice**, and read the universe: is $x$ in $\mathbb{N}$, $\mathbb{Z}$ or $\mathbb{R}$?
2. **Draw a diagram** (Venn diagram or number line) before computing.
3. **Check special cases**: the empty set; the leading coefficient equal to $0$; the discriminant sign.
4. **Verify your answer**: substitute the parameter back; test one value of an interval.
5. **Use complement counting** for "at least one".
6. **On multiple choice**, test one value from each candidate interval in the original inequality — often faster than solving.
7. **Rational inequalities**: never multiply by the denominator; use a sign table.

## 4. Typical traps

- A parameter value that makes two elements equal must be rejected (distinctness).
- $B \subseteq A$ with $B = \varnothing$ is always allowed.
- Brackets: $\infty$ takes a round bracket; strict inequalities give round brackets.
- Multiplying an inequality by a negative number flips the sign.

## Quick self-test

1. $A = \{x \mid x^2 - 5x + 6 = 0\}$, $B = \{x \mid ax - 2 = 0\}$ and $B \subseteq A$. Find $a$.
2. Solve $\dfrac{x + 3}{x - 1} < 2$.

**Answers.** (1) $A = \{2, 3\}$; $B = \varnothing$ if $a = 0$, else $B = \{2/a\}$, so $a = 1$ or $a = \tfrac23$: $a \in \{0, \tfrac23, 1\}$. (2) $\dfrac{5 - x}{x - 1} < 0 \iff \dfrac{x - 5}{x - 1} > 0$: $x < 1$ or $x > 5$.
